# Unslopify UI

AI can build a website in minutes. Getting one that doesn't look like every other AI website takes more work.

Unslopify UI is a place for guidance on making AI-generated websites look and feel better. Think clearer layouts, better typography, useful copy, and fewer default gradients.

Use it with Codex, Claude, Grok, Gemini, or whichever AI assistant you prefer. Give your assistant the guidance along with your project's context, then review and refine the result.

This project is just getting started. Suggestions and contributions are welcome.
